How to install

  1. Click Download for Windows above and open the downloaded FGMS-Registrar-Setup.zip.
  2. Double-click FGMS-Registrar-Setup-….exe inside it.
  3. If Windows says “Windows protected your PC”, click More info, then Run anyway.
  4. Follow the steps. FGMS Registrar is added to the Start menu (and the Desktop if you tick the box). No administrator password is needed.
  5. The first time it opens, choose the school’s folder in Google Drive, and allow network access on private networks so the director’s computer can connect.
Updating? Download and run the new setup the same way. The records are kept: they stay on the computer and in the Google Drive folder, never in the program folder.

Students and teachers

Students and teachers do not need this app. They sign in to the school’s online portal on a phone or computer (Student ID or Teacher ID + PIN). Ask the registrar for the portal address.
